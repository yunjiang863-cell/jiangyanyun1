## 最小默认技术路线（暂定）

沿用现有 HTML，优先采用原生 HTML / CSS / JavaScript，不引入前端框架、构建工具或第三方运行依赖。先确认目标并补齐资源，再根据实际功能决定是否需要框架或后端。

本地预览使用 Python 3 自带的静态 HTTP 服务；Python 仅用于开发预览，不是产品后端。此路线可以调整，不预设登录、支付、管理后台等功能。

## 开发入口

先安装 Git 和 Python 3，然后在终端执行：

```sh
git clone https://github.com/yunjiang863-cell/jiangyanyun1.git
cd jiangyanyun1
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows 可将最后一行替换为：

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8000/downloads/>。在仓库根目录运行服务；直接访问根网址只会显示目录列表。修改文件并保存后刷新浏览器，按 `Ctrl+C` 停止服务。

这是仅供本机预览的开发入口。现有页面可能请求外部资源；本地预览不表示外部服务已接通。静态服务不会执行 PHP，页面引用的 `rank.php` 也未入库。

## 基础检查

1. 预览地址能返回现有 HTML；页面样式不完整是已知资源缺失，不能据此宣称网站可用。
2. 打开浏览器开发者工具的 Network 和 Console，记录缺失文件及脚本错误。
3. 提交前运行 `git diff --check`，检查意外空白；查看 `git diff`，确认没有提交密码、令牌或本地配置。

当前没有自动化测试。新增交互或接口时，再为关键行为增加相应测试。
